How it works, in plain words

  1. The vault starts with $150 trillion of play money. Block 0 (the "genesis" block) puts all of it in the Treasury in the Central Command Hall vault. No more can ever be added.
  2. Every printed bill is recorded by its serial number. When a bill is issued, its face value moves out of the Treasury and onto that serial. Treasury + all bills always equals $150 trillion.
  3. Each block is locked to the one before it. A block carries a fingerprint of the previous block, so changing anything in an old block breaks every block after it.
  4. The bank signs every block. Only the bank's private key can sign, and anyone can check the signature with the public key below. A forger can't make a valid block.
  5. The check letter catches fakes and typos. The last letter of a serial is A plus (the sum of the 8 digits + the face value) counted around the alphabet. A wrong letter means the serial isn't genuine.
  6. Secret codes stop photocopies (Run 2). Each Run 2 bill has its own random code in a VERIFY CODE box, covered with a removable sticky tab. The ledger stores only a scrambled fingerprint of the code (salted PBKDF2-SHA256), never the code. A copier can copy the serial, but the first person to claim the bill with the right code owns it; the bank then records "claimed", and every other bill with that serial is a copy. Run 1 bills have no code and are valid by serial only.
  7. Git history is the clock. Each ledger update is committed to the public GitHub repo, which timestamps it.
